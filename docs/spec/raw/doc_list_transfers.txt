The `GET /api/v1/transfers` endpoint retrieves a paginated list of transfers filtered by creation date range, currency, status, and other optional parameters.

# List all Transfers

Get list of transfers from a specified creation date/time, with optional filters on end creation date/time, buy/sell currency and status. Alternatively, one or neither of the *from* or *to* created_at request fields needs to be populated. In the event that neither or only the to created_at fields are populated, then transfers 30 days in arrears of today or the *to* created_at date will be returned.

## Endpoint

`GET /api/v1/transfers`

## Request Headers

- `Authorization` (string, required)
  Obtain a token via `POST /api/v1/authentication/login` with your API key and client unique identifier. Pass it as `Authorization: Bearer {{ACCESS_TOKEN}}`. Tokens expire after a configurable duration.

## Request Parameters

### Query Parameters

- `batch_transfer_id` (string, format: uuid, optional)
  Batch transfer unique identifier.
- `beneficiary_id` (string, format: uuid, optional)
  Beneficiary unique identifier.
- `from_created_at` (string, optional)
  The start date of `created_at` in ISO8601 format (inclusive).
- `page` (string, optional)
  A bookmark for use in pagination to retrieve either the next page or the previous page of results. You can fetch the value for this identifier from the response of the previous API call. To retrieve the next page of results, pass the value of page_after (if not null) from the response to a subsequent call. To retrieve the previous page of results, pass the value of page_before (if not null) from the response to a subsequent call. The 30-day limit will be removed if `page` is present in the request. Passing page=0 on the very first page will override the 30 days default for null date ranges, enabling a complete search of the transfers.
- `page_size` (integer, format: int32, optional)
  Number of results per page, defaultValue 2000.
- `request_id` (string, optional)
  Transfer `request_id`.
- `short_reference_id` (string, optional)
  Transfer `short_reference_id`.
- `status` (string, optional)
  Status of the transfer.
- `to_created_at` (string, optional)
  The end date of `created_at` in ISO8601 format (inclusive).
- `transfer_currency` (string, optional)
  Transfer currency.

## cURL example

```bash
curl --request GET \
  --url 'https://api.sandbox.airwallex.com/api/v1/transfers' \
  --header 'Authorization: Bearer {{ACCESS_TOKEN}}' \
  --header 'Content-Type: application/json'
```

### Retrieve a list of transfers

Call [Get list of transfers](https://www.airwallex.com/docs/api/payouts/transfers/list.md) to retrieve details for transfers based on specific conditions.

You can specify the date range of transfer creation (`from_created_at` and `to_created_at`, inclusively) within the endpoint URL of the request, and the response will be in the same format as in the response of [Create a new transfer](https://www.airwallex.com/docs/api/payouts/transfers/create.md). You can also use optional parameters such as `transfer_currency` and `status` to filter your transfers, and the pagination parameters (`page_num`, `page_size`) to refine the results.

> **\[WARNING]**
>
> The maximum date range between `from_created_at` and `to_created_at` is **30 days**. Requests that exceed this window return `400 time_range_exceed`. To retrieve transfers over a longer period, paginate with multiple requests each covering at most 30 days.

#### Example request

```shell
curl -G https://api.sandbox.airwallex.com/api/v1/transfers \
  -H 'Authorization: Bearer {{ACCESS_TOKEN}}' \
  --data-urlencode 'from_created_at=2022-10-21' \
  --data-urlencode 'page_num=0' \
  --data-urlencode 'page_size=2000' \
  --data-urlencode 'transfer_currency=USD' \
  --data-urlencode 'status=COMPLETED'
```

# List all Transfers

Retrieve details of transfers.

## Endpoint

`GET /partner-api/v1/transfers`

## Request Headers

- `Authorization` (string, required)
  Obtain a token via partner authentication or OAuth endpoints, then pass it as `Authorization: Bearer {{ACCESS_TOKEN}}`.

## Request Parameters

### Query Parameters

- `from_created_at` (string, format: date-time, optional)
  The start time of `created_at` in ISO8601 format (inclusive).
- `to_created_at` (string, format: date-time, optional)
  The end time of `created_at` in ISO8601 format (exclusive).
- `factor_managed_account_id` (string, format: uuid, optional)
  The unique identifier of the factor managed account.
- `status` (string, optional)
  Status of the transfer.
- `page` (string, optional)
  A bookmark for use in pagination to retrieve either the next page or the previous page of results. You can fetch the value for this identifier from the response of the previous API call. To retrieve the next page of results, pass the value of `page_after` (if not `null`) from the response to a subsequent call. To retrieve the previous page of results, pass the value of `page_before` (if not `null`) from the response to a subsequent call.
- `page_size` (integer, format: int32, optional)
  Number of transfer objects per page. Defaults to `20`.

## cURL example

```bash
curl --request GET \
  --url 'https://api.sandbox.airwallex.com/partner-api/v1/transfers' \
  --header 'Authorization: Bearer {{ACCESS_TOKEN}}' \
  --header 'Content-Type: application/json'
```

## Response

### 200 OK

**Example:**

```json
{
  "items": [
    {
      "amount_beneficiary_receives": 1,
      "factor_managed_account_id": "e1f3c6e3-ba66-4400-83ec-e81553647806",
      "fee_amount": 1,
      "fee_currency": "USD",
      "fee_paid_by": "BENEFICIARY",
      "id": "b05a7b0f-e24f-4339-ab4f-67bf398b2b0a",
      "reference": "payment-2025-01-01",
      "request_id": "ffb277f7-c10d-4e46-ab1e-25acd90a79fc",
      "source_amount": 100,
      "source_currency": "USD",
      "status": "PENDING",
      "target_amount": 100,
      "transfer_currency": "USD"
    }
  ],
  "page_after": "<string>",
  "page_before": "<string>"
}
```

- `items` (array[object], required)
  Paged results.
  - `created_at` (string, format: date-time, required)
    The time when this transaction was created.
  - `factor_managed_account_id` (string, format: uuid, required)
    The unique identifier of the factor managed account.
  - `id` (string, format: uuid, required)
    The unique identifier of the transfer.
  - `reference` (string, required)
    A user specified reference that will be displayed to the beneficiary on the payment transaction with their bank.
    - 1-140 characters long
    - Should not contain emojis.
  - `request_id` (string, required)
    A unique request identifier specified by you for idempotency. Up to 50 characters.
  - `status` (string, required)
    The status of the transfer.
    Possible values:
    - `PENDING` — The transfer is pending to be executed.
    - `COMPLETED` — The transfer is completed successfully.
    - `FAILED` — The transfer is failed.
  - `updated_at` (string, format: date-time, required)
    The time when this transaction was last updated.
  - `amount_beneficiary_receives` (number, optional)
    The total amount the beneficiary receives for this transfer,.
  - `beneficiary` (string, optional)
    Details for the repayment beneficiary.  The schema of the bank_transfer_beneficiary can be referenced from the `beneficiary` field in the  request body in  [create a new beneficiary API](https://www.airwallex.com/docs/api/payouts/beneficiaries/create.md). We only support `LOCAL` as payment method for now.
  - `fee_amount` (number, optional)
    The amount of the fee.
  - `fee_currency` (object, optional)
    The currency of the fee.
  - `fee_paid_by` (string, optional)
    Denotes whether PAYER/BENEFICIARY will be liable for the transfer fees, and it affects the actual amount the beneficiary receives.
    Possible values:
    - `PAYER`
    - `BENEFICIARY`
  - `source_amount` (number, optional)
    The amount of the source transfer.
  - `source_currency` (object, optional)
    The currency of the source transfer.
  - `target_amount` (number, optional)
    The amount of the target transfer.
  - `transfer_currency` (object, optional)
    The currency of the target transfer.
- `page_after` (string, optional)
  The page cursor used for searching after page.
- `page_before` (string, optional)
  The page cursor used for search before page.

You can also use optional parameters such as `transfer_currency` and `status` to filter your transfers, and the pagination parameters (`page_num`, `page_size`) to refine the results.

> **\[WARNING]**
>
> The maximum date range between `from_created_at` and `to_created_at` is **30 days**. Requests that exceed this window return `400 time_range_exceed`. To retrieve transfers over a longer period, paginate with multiple requests each covering at most 30 days.

#### Example request

```shell
curl -G https://api.sandbox.airwallex.com/api/v1/transfers \
  -H 'Authorization: Bearer {{ACCESS_TOKEN}}' \
  --data-urlencode 'from_created_at=2022-10-21' \
  --data-urlencode 'page_num=0' \
  --data-urlencode 'page_size=2000' \
  --data-urlencode 'transfer_currency=USD' \
  --data-urlencode 'status=COMPLETED'
```

If you are registered as a platform account, you can call this endpoint on behalf of your connected accounts by specifying the open ID in the `x-on-behalf-of` header.

The List all Connected Account Transfers endpoint retrieves a paginated, creation-time-sorted list of connected account transfers created by your Airwallex account.

# List all Connected Account Transfers

Get a list of connected account transfers created by your Airwallex account. The transfers returned are sorted by creation time.

## Endpoint

`GET /api/v1/connected_account_transfers`

## Request Headers

- `Authorization` (string, required)
  Obtain a token via `POST /api/v1/authentication/login` with your API key and client unique identifier. Pass it as `Authorization: Bearer {{ACCESS_TOKEN}}`. Tokens expire after a configurable duration.

## Request Parameters

### Query Parameters

- `currency` (string, optional)
  Currency (3-letter ISO-4217 code).
- `destination` (string, optional)
  Airwallex account unique identifier.
- `from_created_at` (string, optional)
  The start date of `created_at` in ISO8601 format (inclusive).
- `page_num` (integer, format: int32, optional)
  Page number, starts from 0.
- `page_size` (integer, format: int32, optional)
  Number of results per page. Default value is 100, minimum 10, maximum 2000.
- `request_id` (string, optional)
  Transfer `request_id`.
- `status` (string, optional)
  Status of the transfer. One of: `NEW`, `SETTLED`, `PENDING`, `SUSPENDED`, `FAILED`.
- `to_created_at` (string, optional)
  The end date of `created_at` in ISO8601 format (inclusive).

## cURL example

```bash
curl --request GET \
  --url 'https://api.sandbox.airwallex.com/api/v1/connected_account_transfers' \
  --header 'Authorization: Bearer {{ACCESS_TOKEN}}' \
  --header 'Content-Type: application/json'
```

A successful 200 OK response returns a paginated list of connected account transfer objects, each containing transfer details, status, fees, and optional card payment and merchant data.

      - `TRANSFER`
    - `type` (string, optional)
      Define the type of fee calculation. If the `source_type` is `CONVERSION`, then the type must be `PERCENTAGE`.
      Possible values:
      - `FIXED`
      - `PERCENTAGE`
  - `application_fees` (array[object], optional)
    Application fees in this transfer.
    - `amount` (string, optional)
      The application fee amount.
    - `currency` (string, optional)
      The currency of the application fee.
    - `source_type` (string, optional)
      Specify the type of source transaction for this application fee.
      Possible values:
      - `CONVERSION`
      - `TRANSFER`
  - `batch_transfer_id` (string, optional)
    Unique identifier of the batch containing the transfer.
  - `beneficiary_id` (string, format: uuid, optional)
    beneficiary_id of the beneficiary contact used to create this transfer.
  - `conversion` (object, optional)
    Conversion details of a transfer with currency conversions.
    - `currency_pair` (string, required)
      The currency pair of the conversion.
    - `rate` (number, required)
      The rate of the conversion.
  - `dispatch_date` (string, optional)
    Actual payout dispatch date. Payouts are dispatched at this date in actual processing. This date could be later than the transfer date.
  - `dispatch_info` (object, optional)
    Additional details populated after the transaction is sent to Airwallex's downstream for processing. Only available for some transfer methods - see [Product Docs](https://www.airwallex.com/docs/payouts/transfers/create-a-transfer.md) for details.
    - `external_reference` (string, optional)
      A reference ID to track a transfer after it's dispatched from Airwallex. For stablecoin transfers, this is the on-chain transaction hash.
    - `external_reference_type` (string, optional)
      The definition of the `external_reference` in the payment system. Possible values include `NETWORK_TRANSACTION_ID` for stablecoin transfers (blockchain transaction hash).
  - `failure` (object, optional)
    Failure details if the transfer is in an error state.
    - `code` (string, optional)
      Failure code.
    - `details` (object, optional)
      Additional failure details.
      - `reason_codes` (array[string], optional)
        Detailed reason code.
      - `type` (string, optional)
        Failure type.
    - `message` (string, optional)
      Failure message.
  - `lock_rate_on_create` (boolean, optional)
    Denotes whether to lock the conversion rate for a scheduled transfer with value `TRUE` or `FALSE`.This field should only be specified when a conversion is involved. If not specified, the default value is `TRUE`.
  - `metadata` (object, optional)
    A set of key-value pairs for storing your own data together with the transfer.
  - `payer_id` (string, format: uuid, optional)
    payer_id of the payer contact used to create this transfer.
  - `prepayment` (object, optional)
    Prepayment details for a schedule transfer with currency conversions at a confirmed rate.
    - `amount` (number, required)
      The prepayment amount to be paid.
    - `currency` (string, required)
      The prepayment currency.
  - `remarks` (string, optional)
    Additional information about this transfer, which will not be passed to the beneficiary.
  - `swift_charge_option` (string, optional)
    (For SWIFT transfers only), specify who should bear SWIFT charges, either `SHARED` (default) or `PAYER`.
- `page_after` (string, optional)
  The page cursor used for searching after page.
- `page_before` (string, optional)
  The page cursor used for search before page.
