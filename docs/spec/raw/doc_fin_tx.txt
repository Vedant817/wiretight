The List all Financial Transactions API endpoint retrieves a paginated list of financial transactions that contributed to an Airwallex account balance, with optional filters for date range, batch, currency, source, and status.

# List all Financial Transactions

Get a list of financial transactions that contributed to the Airwallex account balance from a specified creation date/time, with optional filters on end creation date/time, batch_id and status.

## Endpoint

`GET /api/v1/financial_transactions`

## Request Headers

- `Authorization` (string, required)
  Obtain a token via `POST /api/v1/authentication/login` with your API key and client unique identifier. Pass it as `Authorization: Bearer {{ACCESS_TOKEN}}`. Tokens expire after a configurable duration.
- `x-on-behalf-of` (string, optional)
  Unique identifier of the connected sub account.

## Request Parameters

### Query Parameters

- `batch_id` (string, optional)
  Batch unique identifier of the financial transaction.
- `currency` (string, optional)
  The currency (3-letter ISO-4217 code) of the financial transaction.
- `from_created_at` (string, optional)
  The start time of `created_at` in ISO8601 format (inclusive).
- `page_num` (integer, format: int32, optional)
  Page number, default is 0, max is 2000.
- `page_size` (integer, format: int32, optional)
  Number of results per page, default is 100, max is 1000.
- `source_id` (string, optional)
  The source unique identifier of the transaction.
- `status` (string, optional)
  Status of the financial transaction, one of: `PENDING`, `SETTLED`.
- `to_created_at` (string, optional)
  The end time of `created_at` in ISO8601 format (inclusive).

## cURL example

```bash
curl --request GET \
  --url 'https://api.sandbox.airwallex.com/api/v1/financial_transactions' \
  --header 'Authorization: Bearer {{ACCESS_TOKEN}}' \
  --header 'Content-Type: application/json'
```
